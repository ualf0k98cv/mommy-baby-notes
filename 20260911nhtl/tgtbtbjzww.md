# 得了妊娠糖尿病的症状

> 更新时间：2026-09-11 (UTC+8)

都说我们的出生日就是妈妈的灾难日，其实，何止是那一天妈妈在受苦，在孕期的时候很多孕妈的身体都会有不适之处，如果稍加不注意，可能还会患上一些严重的疾病，妊娠期糖尿病就是其中典型的一种疾病。要想尽早的解决这种疾病，孕妈们就需要了解该病的症状。

**得了妊娠糖尿病的症状**

1. 孕妇出现“三多”情况，即吃得多、喝得多、尿得多。不过并非出现这些症状就意味着一定患病，因为单看这三个“多”，它们都是孕期会有的正常现象。

2. 孕妇被诊断出羊水过多或者胎儿巨大。

3. 孕妇体重不正常。体重大于90kg或者比怀孕前增长了超过20斤，建议这类孕妇去医院查血糖。

4. 外阴道念珠菌感染频发。

**妊娠期糖尿病的发病原因**

怀孕期间期发生血糖偏高的原因通常有以下几点：

1.高龄怀孕：超过30岁的女性孕期患糖尿病等并发症的机率更高。在合适的年龄段内怀孕，身体既能承受得住，胎儿的质量也高。

2.体形肥胖：肥胖不是一天养成的，与长期的成活习惯、饮食习惯有关。肥胖者体内的脂肪细胞肥大，对胰岛素的敏感度较低，这就加重了胰岛的工作负荷，久而久之胰岛会被累垮，血糖自然无法得到有效控制。女性在怀孕后吃的太好控制不住体重容易患上糖尿病，本身就肥胖的女性更是如此。

3.遗传原因：种族、地区和家族病史对产妇是否换糖尿病也有一定影响。

妊娠期糖尿病不是一天两天就会患上的，其主要还是和孕妈的生活习惯和个人体质有关系，为了减少这种疾病发生的可能，孕妈们就要时刻注意着自己的生活状态，均衡饮食，在保证了充足营养之后就不要大吃大喝了，同时还有经常锻炼身体，身体素质好的人患病的几率比一般人都要小的多。
