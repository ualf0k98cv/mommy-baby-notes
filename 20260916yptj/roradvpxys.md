# 深化联动协作 共筑健康防线

> 更新时间：2026-09-16 (UTC+8)

为进一步深化城市医疗集团建设，做实做细分级诊疗工作，加强联动协作，近日，漳州市医院副院长阮敏毅带领外联部、医务科、门诊部、呼吸与危重症医学科、急诊科等科室相关人员前往漳州市人民医院开展走访座谈。

**前期协作见成效**

今年6月，漳州市医院与漳州市人民医院正式开启呼吸与危重症医学科双向转诊通道，并安排高级医生定期到人民医院查房、会诊，建立了常态化深度协作机制，形成呼吸患者“急性期救治+稳定期康复”的闭环管理，目前运行顺畅，已转诊患者数十例。

**座谈共商促合作**
座谈会上，人民医院相关负责人对目前呼吸与危重症医学科协作模式予以积极的肯定与建议，并详细介绍了在医疗服务能力建设、人才队伍培养方面的工作进展，提出学科建设、技术帮扶、人才培训等方面的需求。阮敏毅副院长表示，漳州市医院作为城市医疗集团牵头单位，将以呼吸与危重症医学科共建为切入点，充分发挥自身技术、人才、管理优势，精准对接人民医院需求，在专科共建、人才带教、技术推广等方面加大帮扶力度，推动优质医疗资源下沉与共享。双方围绕双向转诊流程优化等具体事宜展开深入探讨，达成多项共识。

此次走访座谈，进一步密切了漳州市医院与漳州市人民医院的沟通联系，为后续深化合作、实现资源共享与优势互补奠定了坚实基础。双方将以医疗集团为纽带，携手共进，持续加强学科共建，提升区域医疗服务整体水平，为漳州百姓提供更加优质、高效、便捷的健康服务。
