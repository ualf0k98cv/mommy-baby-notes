# 【科普活动月】你给宝宝补维生素D了吗？

> 更新时间：2026-09-17 (UTC+8)

宝宝需要补充维生素D，大家都知道。

但是补充维生素D的问题还是让不少家长头疼，

我们一起来看看都有哪些问题吧。

0

**1**

为什么要补充维生素D

宝宝缺乏维生素D会使体内钙磷代谢紊乱，如不及时治疗会导致生长中的骨出现畸形，即老百姓常说的佝偻病，早期出现易激惹、烦躁、汗多等，后遗症期常见的骨骼畸形如方颅、鸡胸、漏斗胸、X型腿、O型腿等。

0

**2**

维生素D缺乏的原因

母亲：围生期储存不足。

宝宝：户外活动少、日光照射不足，生长过快，反复呼吸道感染、慢性消化道疾病、肝肾疾病。

0

**3**

怎么预防维生素D缺乏

（1）母亲：孕妇应经常户外活动，进食富含钙、磷的食物。妊娠后期为冬春季的妇女宜适当补充VitD 400～1000IU/d（10～25μg/d），以预防先天性佝偻病的发生。使用VitAD制剂应避免VitA中毒，VitA摄入量<1万IU/d。

（2）户外活动：在日光充足、温度适宜时每天带宝宝户外活动1～2小时，充分暴露皮肤。

（3）VitD补充：

1）婴儿（尤其是纯母乳喂养儿）生后数天开始补充VitD 400 IU/d（10 μg/d）。

2）高危人群补充：早产、双胎或多胎、低出生体重儿生后即应补充VitD 800IU/d（20μg/d），3个月后改为400I U/d（10 μg/d）。

3）1-18岁：VitD每日需要量是600 IU（10μg/d），户外活动1-2小时，同时适当进食进食含VitD丰富食物如动物肝脏、牛奶、海鱼、鸡蛋等。夏季阳光充足，户外活动多可停服或减服。

0

**4**

特别提醒

维生素D缺乏和过量都会导致身体损害，每个宝宝的具体情况也不尽相同，建议定期带宝宝做儿保，在医生的指导下正确服用维生素D。
